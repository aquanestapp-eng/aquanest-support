# AquaNest Support Site

This directory is intended to be published as a separate public GitHub Pages repository.

Files:

- `index.html`: landing page
- `support.html`: App Store Support URL
- `privacy.html`: App Store Privacy Policy URL
- `terms.html`: terms of use page

Suggested repository name:

- `aquanest-support`
- `aquanest-pages`
- `hydration-support-site`

After creating a new public GitHub repository, copy these files there and enable GitHub Pages.
